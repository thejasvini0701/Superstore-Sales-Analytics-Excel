# Superstore Sales Analytics – Excel Project

## Project Overview

This project analyzes Superstore sales data using Microsoft Excel.

The project focuses on exploring sales performance across different categories, regions, years, customer segments, and shipping modes.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Tables
* Data Cleaning
* Data Analysis
* Dashboard

## Workbook Structure

* Raw Data
* Cleaned Data
* Pivot Tables
* Analysis
* Dashboard

## Key Analysis

* Total Sales
* Total Orders
* Average Sales
* Average Shipping Days
* Sales by Category
* Sales by Region
* Sales by Year
* Sales by Customer Segment
* Sales by Ship Mode
* Top Products

## Dashboard

The dashboard provides a visual summary of the sales analysis using KPI cards and charts.

## Project Files

* `Superstore_Sales_Analytics.xlsx` – Complete Excel analysis
* `Dashboard.png` – Dashboard preview

## Key Findings

* Technology recorded the highest sales among the categories.
* West recorded the highest sales among the regions.
* 2018 recorded the highest sales among the years.
* Consumer was the highest-selling customer segment.
* Standard Class had the highest sales among shipping modes.
